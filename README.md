# Analog Temperature Controller (Pure Analog, Proteus)

This repository contains a complete purely analog temperature controller design for Proteus simulation using:

- 10 kΩ NTC thermistor (sensor input)
- 10 kΩ potentiometer (20–26°C setpoint)
- LM393 dual comparator (decision logic)
- IRF540N MOSFETs (power stage)
- Two 12 V fans (cooling) + one 12 V heater (heating)
